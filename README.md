# mtfind

Поиск подстроки в текстовом файле по маске с использованием многопоточности.

## Сборка

```bash
cmake -S . -B build
cmake --build build -j
ctest --test-dir build --output-on-failure
```

## Запуск

```bash
./build/mtfind <file> "<mask>"
```

## Формат вывода

```
<count>
<line> <position> <match>
...
```

Нумерация строк и позиций — 1-based. Порядок вхождений совпадает с порядком в файле.
